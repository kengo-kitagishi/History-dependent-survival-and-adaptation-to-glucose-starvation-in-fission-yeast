2026-09-24。タスクの開始時にこのままClaude CodeまたはCodexへ貼る。必ず最初に入力ファイル・HTML・解析版・イベント定義を調べる。ユーザーと図を確認しながら進めるので、一度に全系列を自動採用・除外しない。結論や閾値を創作しない。

## A. 0.0055%条件のHTMLレビューと対象系列選定（約2時間）

```text
QPI_Omni の 260517 解析について、0.0055% glucose 期を含む飢餓条件の解析対象系列を、HTMLを私と一緒に見ながら決めたい。

最初に repo の CLAUDE.md、既存タスク「260517 の系譜・時系列 HTML を見て CSV を整える」、docs/channel_classification_260517.yaml、解析出力・HTMLギャラリーの場所と生成条件を確認する。条件名の0.0055%がどのframe区間に当たるかを metadata と時刻列で照合し、古い予定値を無検証で採用しない。

HTMLでチャネル一覧を見せ、私が指定した Pos/ch や mother 以外の娘細胞についても、追跡できる限り個別の位相像・マスク・長さ/幅/面積・体積・質量・密度の時間変化を開いて比較できるようにする。表示手段を先に確認し、使えない表示をできると言わない。チャネルごとに追跡IDの継続、細胞の入れ替わり、誤分裂、誤接続、欠測、端への接触、飢餓期の輪郭変化を私と確認する。

判断は系列または個体ごとに「採用／除外／保留」で記録し、根拠frame・問題・私の発言を短く残す。母細胞と娘細胞を分ける。同じチャネル内の複数細胞は独立反復として数えない。画像が見られない・ID対応が曖昧な場合は保留にする。「追跡が悪い」と私が言った個体は、その箇所を示し、私の判断を記録してから除外する。

セッションごとに review_manifest.csv（condition, Pos, ch, cell_id, status, reason, frames, reviewer_note, source_html, source_csv, analysis_version）を更新し、未確認件数と保留を表示する。作業が中断した場合は保存済みmanifestを読み直して未確認分から再開する。レビューが終わったら、条件ごとの採用/除外数、追跡可能な細胞数とチャネル数、曖昧点を報告する。この依頼では、対象リストを私に見せて合意を得るまで統計解析や結果図の生成へ進まない。
```

```text

まず解析計画を1画面分で提示する。各推定量の操作的定義、対照群、n（細胞・チャネル・実験を別々に）、欠測/QC処理、系列内相関への対応、出力図とsource-dataを含める。私が開始を指示したあと実行する。細胞が同じチャネルやmother系譜を共有する構造を保ち、細胞を独立反復として検定しない。死、lysis、追跡停止、再増殖を区別する。全ステップで入力manifest・解析版・除外理由を出力へ残す。

結果はまずQCと小さなpreviewを見せる。効果の向きだけで原因や予測を結論しない。図には操作的定義、単位、n、誤差帯/信頼区間の意味を書く。再開できる中間CSVと実行記録を保存し、最後に未解決点と再現コマンドを報告する。
```
