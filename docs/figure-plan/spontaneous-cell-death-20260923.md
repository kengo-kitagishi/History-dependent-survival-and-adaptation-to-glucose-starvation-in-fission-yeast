## 何を明らかにするか

主題の第一案は「通常増殖時の変動を基準に、自発的な細胞死に至る形態・体積・乾燥質量・密度の経過を記述する」。return map は通常時の世代間変動を示す補助パネルに置く。死亡予測や能動的な密度制御を結論として先取りしない。

最小構成は2図：通常増殖の基準（fig:growth_reference）→ 自発的細胞死の形態と経過（fig:spontaneous_death）。死亡前の逸脱時刻を十分な例数で定義できた場合だけ、集団比較を3枚目に独立させる。

## 最初に確定する解析単位・イベント

- 主解析は追跡対象の母細胞。娘細胞は画像内で示し、死亡が同一チャネル内で続く事例は注記する。娘まで含める場合は別集計とし、同一チャネルの細胞を独立な実験反復と数えない。
- `cell_id` と画像上の個体を照合する。rank=1 は位置順位なので、死亡・流出後に別個体へ入れ替わり得る。rankだけで同じ細胞とみなさない。
- イベント表には `onset_frame`（形態異常開始）、`last_division_frame`、`lysis_frame`、`last_confirmed_alive_frame`、`first_confirmed_dead_frame`、`last_valid_measurement_frame`、根拠画像・注釈者・確信度を別列で保存する。分からない値は欠損とする。
- 「破裂確認」「非溶解性の死亡判定」「分裂停止のみ」「流出・追跡不良」「判定不能」を区別する。非溶解性の死亡は判定根拠と観察期間が必要。増殖停止・質量10 pg未満・外れ値フラグを死亡の確定条件にしない。
- 死亡時刻を一点に確定できなければ、最後の生存確認と最初の死亡確認の区間を残す。時刻合わせの主図は、まず破裂が画像で確認できる例に限定する。
- 密度は採用する質量・体積推定をそろえて `ρ=1000 M[pg]/V[µm³]` [mg/mL] と定義する。RIを併記する場合は換算基準も記す。異なる再処理版の値を混ぜない。

**イベントの混同が実際にある例**：Pos20_ch06 の `death_frame.txt=1250` は YAML では伸長開始、破裂は約1561。Pos30_ch04 の900も伸長開始で、破裂は約1300。現在の `overlay_elongation_death_pair.py` は開始frameを `death_frame` として縦線に用いる。これを死亡前時間へそのまま変換しない。

## 図1：通常増殖時の基準と return map

問い：同じ栄養条件で通常増殖している細胞では、密度は周期内・周期間でどの範囲を動くか。

183 mm幅を想定した2段構成。上段は代表時系列を広く、下段は3量を同じ幅にする。

| 位置 | パネル | 描くもの |
|---|---|---|
| 上段左2/3 | A 通常増殖の代表系譜 | 密度の時系列、分裂位置、必要な箇所だけ位相像。代表の選定基準を残す |
| 上段右1/3 | B 周期内の変化 | 周期位相0–1での密度。薄線=各系統の要約、太線=集団要約。個体差の帯と推定CIを区別 |
| 下段3列 | C–E return map | V、M、ρの出生値 `x_n` 対次の出生値 `x_(n+1)`。恒等線、回帰、傾きと系統単位の95%CI、ペア数と系統数 |

return map の要件：

1. 横軸・縦軸とも出生値に統一する。周期平均や分裂直前値を混ぜない。`x_(n+1)-x_n` 対 `x_n` は補助図に置けるが、主図と同じペアを使う。
2. 完全な隣接周期のみをペアにする。QCで周期を落とした後、離れた周期を隣接とみなして接続しない。系譜・周期番号・両出生frameをsource CSVに残す。
3. 通常時の基準には phase1 のみを使う。飢餓後のrevivedラベルで選ぶと将来の運命で基準群を選別するため、別の感度解析として区別する。
4. 生の値での回帰と系統内で中心化した回帰を比較する。中心化に使った系列長を保存し、短系列の平均推定の影響を検討する。
5. 負の差分傾きだけから能動的補正を主張しない。`Cov(x,y-x)=Cov(x,y)-Var(x)` なので、独立な次値でも負になる。シャッフルは同じペア構成・系列長・中心化の手順を適用する。
6. 現行 `fig_return_maps.py` はQC後の隣接行を接続し、`lineage_claim_ladder.py` のCIは点単位の再標本化。今回の系統単位の不確かさ評価に合わせて更新が必要。
7. 密度のVAR(1)比較や空チャネル由来shamは測定・モデル依存の検証として扱う。差が出ただけで密度の直接制御を確定しない。

## 図2：自発的細胞死の形態と経過（中心図）

問い：栄養存在下で死亡する細胞は、死亡前にどのような形態・物質量の変化を示すか。

183 mm幅。**上段は形態画像、中段は同じ細胞の定量、下段は全候補の要約**。画像と曲線を同じ色・細胞ID・時刻で対応させる。

| 位置 | パネル | 描くもの |
|---|---|---|
| 上段全幅 | A 位相像の時系列 | 行=通常例／膨潤候補／伸長候補、列=変化前／開始付近／進行中／破裂直前／破裂後。実際の時刻差をラベルに書く |
| 中段左 | B 形態 | Aと同じ個体の長さL・幅W（軸を分けて縦積み）。伸長と横方向の膨らみを分ける |
| 中段右 | C 物質量 | 同じ横軸で体積V・乾燥質量M・密度ρを3段。通常群の比較範囲、開始線と破裂線を区別 |
| 下段左 | D イベント整列 | 破裂確認例をt=0でそろえたρ（必要ならVも）。薄線を残し、時点ごとの有効細胞数を付ける |
| 下段右 | E 形態分類 | 膨潤・伸長・混合・その他・判定不能のn/N。分類が安定しなければ一覧図に置換 |

画像要件：同じpixel size・向き・位相カラースケール・スケールバー。マスク輪郭は必要なコマに付ける。選定理由を残し、印象的な2例だけで全死亡を代表させない。Pos20_ch06/Pos30_ch04 は伸長候補であり、膨潤例は画像を見て選ぶ。現状、外付け実験画像はこのMacに接続されていない。

解析要件：

- 形態はまずL、W、L/W、面積で記述する。長さと幅の変化を見てから形態分類の閾値・持続時間を固定し、密度を分類条件に使わない。
- 時間窓の初案は破裂前24 h。開始から破裂までが長い例は代表パネルで全経過を表示し、集団図は12/24/48 hで感度を確認する。欠測区間を長く補間しない。
- 位相像上の輪郭崩壊以後は、細胞全体のV・ρが定義できるか確認する。崩壊前で定量を止めても、破裂後画像は別に提示できる。
- 大きなV・高いρ・長い周期を異常値として一律除去すると、調べたい死亡前変化を消す。画像で確認する測定失敗と生物学的な変化を区別する。
- 膨潤・変形では棒状体積モデルの影響を点検し、形状に適した別推定との比較を付録に置く。Vとρの逆方向の変化はρ=M/Vにも由来するため、独立した証拠として二重に数えない。
- 通常群は同じ実験・可能なら同じ視野・近い実験時刻・周期状態から選ぶ。死亡群と同じ処理を適用する。通常群の比較時刻は擬似イベント時刻と明記する。
- nは細胞・チャネル・実験を別記する。2例の伸長群は個別例として示す。独立実験の反復が無ければ条件一般への推論は行わない。
- 「死亡前の逸脱」は同一時刻・周期を考慮した通常群の範囲と比較する。範囲の定義、超過の持続時間、測定床を先に固定してから到達時刻を評価する。これは予測精度の検証とは別。
