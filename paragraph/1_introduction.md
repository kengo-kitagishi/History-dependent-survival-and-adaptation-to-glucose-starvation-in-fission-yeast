## Stage 2: パラグラフレベル
 
### Section 1: General background
- Para A: グルコースは主要エネルギー源; 飢餓は普遍的ストレス; 微生物・がん・代謝疾患への関連
- Para B: 遺伝的に同一な集団でも飢餓への応答は不均一; 表現型多様性の存在
- Para C: その不均一性は「過去の経験（歴史）」に依存する; 歴史依存的応答の実例
- Para D: 歴史依存性を担う「細胞の記憶」の実体は何か？ → この問いが本研究の出発点
 
### Section 2: Technical background
- Para E: 休眠（dormancy/quiescence）の概念; 死でも増殖でもない第三の状態; 酵母での実例
- Para F: 細胞内マクロ分子クラウディングの概念と生物学的重要性; excluded volume effect
- Para G: 飢餓時の細胞質ガラス転移（fluid→solid-like）とdormancyの関係（Munder 2016）
- Para H: LLPSと凝縮体形成; クラウディングがLLPSを促進; ストレス顆粒・P-bodyの役割
- Para I: 細胞内流動性（intracellular fluidity/microrheology）の概念; 異常拡散と粘弾性
 
### Section 3: Specific problem
- Para J: 既存手法の限界（集団平均; 侵襲的ラベル; 時間分解能）
- Para K: 単一細胞レベルでのクラウディング・流動性の「歴史依存的変化」と「生存との関係」は未解明
 
### Section 4: This thesis
- Para L: S. pombeをモデルに; QPM（クラウディング）+ GEM passive microrheology（流動性）の組み合わせ
- Para M: 研究アプローチと本論文の構成
