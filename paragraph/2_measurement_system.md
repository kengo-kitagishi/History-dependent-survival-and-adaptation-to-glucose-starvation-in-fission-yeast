# 第2章 QPIによる長期1細胞計測系の構築 — paragraph

## 2.3 定量位相イメージングの原理

### 2.3.1 位相遅れと共通光路法

**P1 位相遅れと QPI**
- Topic: 細胞と培地の屈折率差は透過光の位相遅れになる。
- Evidence: Δφ(x) = (2π/λ)∫₀^{h(x)}[n_cell(x,z) − n_0]dz。可視光 400–800 THz の振動は直接記録できないので強度に変換する。位相差・DIC は光学的に変換するが定量値ではない。QPI は位相を定量する（Park 2018）。
- Implication: 位相を定量できれば屈折率差、すなわち乾燥質量に届く（2.1）。
- Bridge: 干渉計の組み方。

**P2 common-path 法**
- Topic: 試料の後ろに干渉計を組み、2光が素子を共有する。
- Evidence: 振動・ずれに強い、系が小さい、出力ポートにそのまま組める。
- Implication: 数日のタイムラプスに向く（2.1.2 の条件 (2)）。
- Bridge: 分解能は対物で決まる。

### 2.3.2 対物レンズによる帯域制限

**P3 帯域制限**
- Topic: 対物レンズは NA/λ で切る空間周波数フィルタ。
- Evidence: Ũ_transmitted = Ũ_0·P、P は半径 NA/λ の瞳関数。Abbe 限界 λ/NA（コヒーレント）。
- Implication: 2.4 の円窓の半径がこれに対応する。
- Bridge: 位相を強度から取り出す。

### 2.3.3 オフアクシス干渉による位相の回復

**P4 干渉による位相の回復**
- Topic: 物体光を参照光と干渉させると位相が強度に現れる。
- Evidence: I = |U_s + U_r|² = A_s² + A_r² + 2A_sA_r cos(φ_s − φ_r)。on-axis では4項が Fourier 空間で同じ領域を占める。
- Implication: そのままでは位相を含む項だけを取り出せない。
- Bridge: off-axis で分ける。

**P5 off-axis 配置とホログラムの式**
- Topic: 物体光にキャリア波数を与え、参照光を準平面波にする。
- Evidence: 参照光はピンホールで U_{r,m,n} = A_r。物体光は格子で U_{s,m,n} = (1/M²)A_s e^{iφ_{m,n}} e^{−i(k_m m + k_n n)}。I^DH = |U_s + U_r|² = J^non-int + J^int e^{−i(k·r)} + c.c.、J^non-int = |U_s|² + |U_r|²、J^int = U_s U_r*。
- Implication: 2.4 の再構成と 2.9.1 の位相感度の理論はこの式から出発する。
- Bridge: Fourier 空間でどう分かれるか。

**P6 Fourier 空間での分離**
- Topic: 3成分が Fourier 空間で分かれる。
- Evidence: 非干渉項は原点、干渉項とその複素共役は原点から ±k^off の2か所。+1次を逆 FT すれば U_s、φ = arg U_s。
- Implication: 1枚のホログラムから位相が取れる（2.1.2 の条件 (2)）。
- Bridge: 再構成の手順（2.4）。

## 2.4 位相像の再構成

**P1 再構成の手順**
- Topic: ホログラム1枚から位相像を得る手順は5段階。
- Evidence: (1) 2D 離散 FT。スペクトルは非干渉項と、±k^off に離れた干渉項の3成分。(2) +1次サイドバンドの中心を見つけ、e^{+i(k_m m + k_n n)} を掛けて原点へ移す。(3) 半径 r = (NA/λ)·N·Δp 画素の円窓で切る。(4) 2D 逆 FT で複素場、その arg が位相。(5) 2π の折り返しを reliability-ordered 法（Herráez 2002）で外す。コードは skimage.restoration.unwrap_phase（同じ算法）。図 fig:reconstruction。
- Implication: 円窓の半径は対物の NA で決まるので、位相像の分解能は光学系で決まり、処理では変わらない。
- Bridge: この位相にはまだ照明の波面と流路の位相が乗っている。

**P2 背景の除去**
- Topic: 同じ視野の、細胞のない位相像（参照像）を引く。
- Evidence: φ = arg[LP(I_sample e^{…}) / LP(I_ref e^{…})]。複素場の比の arg なので位相の差になる。残るオフセットは細胞のない領域の平均で除く。OPD に直すなら φλ/2π だが、以降は位相 φ（rad）で扱う。
- Implication: 照明の波面と流路の位相は参照像と共通なので、これで消える。
- Bridge: mother machine では細胞のそばに培地だけの領域が残らないので、参照像をどう取るかが問題になる。取り方は 2.7.3、どの参照像を引くかは 2.8.1。

**P3 分解能と Fourier 面のパラメータ**
- Topic: 位相像の画素数と画素サイズは NA と視野で決まる。
- Evidence: カットオフ f = NA/λ（Abbe 限界 λ/NA、コヒーレント照明）。N×N 画素・物体面画素 Δp のホログラムで FOV = NΔp。円窓の直径 D_ap = 2·round((NA/λ)·FOV)+1 画素（コード qpi.py の aperturesize と同じ式）。再構成画素 Δp_recon = FOV/D_ap ≈ λ/2NA。
- Implication: 位相像の画素は分解能要素の半分で、Nyquist をちょうど満たす。
- Bridge: 生ホログラムの側にも条件がある。

**P4 サンプリング条件**
- Topic: 条件は2段階。
- Evidence: 生ホログラムは Δp < λ/2NA。干渉縞を写すので実際は 2〜4 倍の余裕をとる。位相像は 1 分解能要素 λ/NA ≈ 2 画素。
- Implication: 生ホログラムの余裕は、干渉項が Nyquist を超えないという 2.5 の設計条件 (ii) と同じ要求。
- Bridge: 我々の系の値。

**P5 我々の値**
- Topic: 我々の系はこの条件を満たす。
- Evidence: λ = 658 nm、NA 0.95、40×、カメラ画素 3.45 µm。Δp = 3.45/40 = 86.25 nm。FOV = 2048 × 86.25 nm = 176.64 µm。Abbe 692 nm。Nyquist 346 nm。余裕 346/86.25 = 4.0。(NA/λ)·FOV = 255.0 → D_ap = 2·round(255.0) + 1 = 511。Δp_recon = 176.64 µm / 511 = 346 nm。
- Implication: 位相像は 511×511 画素、画素 0.346 µm。論文の値と一致する。
- Bridge: k^off をどの範囲に置くかが光学系の設計条件になる → 2.5。

## 2.5 光学系

### 2.5.1 設計条件

**P1 何を決める節か**
- Topic: キャリア波数 k^off をどこに置くかで、1枚のホログラムから位相が取り出せるかどうかが決まる。
- Evidence: k^off = 2π/Λ（Λ はセンサ面での縞の周期）。小さすぎると Fourier 空間で干渉項が非干渉項と重なり、2.4 の円窓で切り出せない。大きすぎると縞が画素より細かくなり、センサが記録できない。
- Implication: k^off には下限と上限があり、どちらも NA・倍率 M・画素ピッチだけで決まる。
- Bridge: 下限から。

**P2 下限（重なり）**
- Topic: 干渉項と非干渉項が Fourier 空間で重ならない条件。
- Evidence: 対物は NA/λ より高い空間周波数を通さない（2.3.2）ので、試料の情報は半径 2πNA/(λM) の円板で尽きる。その外は雑音だけ。干渉項 J^int = U_s U_r* は参照光が準平面波なので同じ半径。非干渉項 J^non-int はスペクトルの自己相関なので半径は2倍。中心の間隔 k^off が半径の和 3 × 2πNA/(λM) を超えればよい。
- Implication: k^off ≥ 3(2πNA/λM)。
- Bridge: 上限。

**P3 上限（Nyquist）**
- Topic: 縞がセンサの画素で記録できる条件。
- Evidence: 縞の空間周波数が Nyquist 周波数（f_pitch の半分）を超えると折り返す。記録されるのは中心 k^off・半径 2πNA/(λM) の円板全体なので、その最も高い周波数が Nyquist 以下。限界は各軸ごとに掛かるので、キャリアを画素格子の対角方向に置くと各軸の成分が k^off/√2 に下がり、軸方向より大きな k^off を許せる。本研究の格子はこの向き（2.5.3 の実測 (599, 597) 画素）。
- Implication: k^off/√2 + 2πNA/(λM) ≤ πf_pitch。合わせて 3·2πNA/(λM) ≤ k^off ≤ √2π(f_pitch − 2NA/(λM))。
- Bridge: 本研究の値。

**P4 本研究の範囲**
- Topic: 数値を入れる。
- Evidence: NA 0.95、M 40、λ 658 nm、画素 3.45 µm（f_pitch = 2.90×10⁵ m⁻¹）→ 下限 6.80×10⁵、上限 9.68×10⁵ rad/m。
- Implication: この範囲に k^off を収めるように光学系を組んだ。
- Bridge: 構成（2.5.2）。

### 2.5.2 構成

**P2 構成**
- Topic: common-path off-axis DH（diffraction phase microscopy）を Ti-E の出力ポートに組んだ。
- Evidence: 658 nm・20 mW LD（LP660-SF20）→ コリメータ（CFC2-B, f = 2 mm）→ 試料 → 40×/0.95 乾燥系（CFI Plan Apochromat Lambda D, MRD70470）→ 像面の Ronchi 格子 120 lines/mm（#66-342）→ 4f リレー 2×ACT508-200-A（f = 200 mm）→ Fourier 面の 25 µm ピンホール（P25K）で 0 次を参照光、1 次はそのまま物体光、他の次数は遮る → CMOS acA2440-75um（2448×2048、3.45 µm、FWC ≈ 10 ke⁻）。生ホログラム 2048×2048、位相像 511×511・0.346 µm。図 fig:qpi_optical_system。
- Implication: 2光が同じ光路を通るので振動と光学系のずれに強い（2.1.2 の条件 (2)）。
- Bridge: 格子の周期が k^off を決める。

### 2.5.3 オフアクシス配置の検証

**P3 格子から決まる k^off**
- Topic: k^off = 2π/8.33 µm = 7.54×10⁵ rad/m。
- Evidence: 格子 120 lines/mm、4f リレーの倍率 1 なのでセンサ面でも周期 8.33 µm。
- Implication: P1 の範囲に入る。
- Bridge: 実測で確かめる。

**P4 off-axis 配置の検証**
- Topic: 実測のキャリア周波数が格子からの計算と一致する。
- Evidence: 2048² ホログラムの FT で DC (1024, 1024)、+1 次の中心 (1623, 1621)、ずれ (599, 597) 画素、大きさ 845.8 画素。Δf_sensor = 1/(2048 × 3.45 µm) = 141.5 m⁻¹。f = 845.8 × 141.5 = 1.20×10⁵ cycles/m → k_exp = 7.53×10⁵ rad/m。
- Implication: 格子による off-axis 配置は設計どおり。
- Bridge: 位相ノイズの実測は 2.9。

## 2.6 マイクロ流路デバイス

### 2.6.1 mother machine の原理

**P1 mother machine の原理**
- Topic: 細胞を同じ視野に数日とどめ、子孫を除きながら培地を一定に保つために mother machine を使う。
- Evidence: 主流路1本と、それに垂直な行き止まりの観察チャネル多数。チャネル幅は細胞1個分。閉端の母細胞はとどまり、娘は主流路へ押し出されて流される。培地は拡散で秒の桁で届き、取り込み（分の桁）より速い（Wang 2010）。分裂酵母でも老化・寿命の計測に使われた（Nakaoka 2017）。図 fig:mm_schematic。
- Implication: 2.1.2 の条件 (1) 長期の1細胞追跡を満たす。
- Bridge: 本研究のデバイスの寸法。

### 2.6.2 デバイスの構成

**P2 デバイスの構成**
- Topic: Nakaoka 2017 の設計に倣って自作した。
- Evidence: 観察チャネル 幅 5.3 µm × 高さ 6.2 µm。主流路（ドレイン）幅 214 µm × 高さ 19.75 µm（2026-08-20 に本人が確定した値。長さ・間隔・本数は設計ファイル待ち）。高さが2段階なので鋳型は SU-8 2層。両端をチューブでシリンジと廃液につなぎ、2 mL/h で灌流。図 fig:mm_layout。
- Implication: チャネルの幅と高さが細胞1個分なので、細胞は1列で増える。
- Bridge: 作製の工程。

### 2.6.3 作製

**P3 鋳型とフォトマスク**
- Topic: 鋳型はシリコンウェハ上の SU-8 2層。
- Evidence: マスクは μMLA（Heidelberg）でマスクブランクス（Clean Surface Technology）に描画、チャネルとドレインで別。観察チャネル層: SU-8 2 + 3005 を 3000 rpm 30 s、65 °C 1 min・95 °C 2 min、MA-20 で 5 s × 3 露光、65 °C 1 min・95 °C 3 min、現像・IPA。ドレイン層: SU-8 3010 を 1500 rpm 30 s、65 °C 1 min・95 °C 8 min、1層目のマークに合わせて 30 s 露光、65 °C 3 min・95 °C 10 min、現像。
- Implication: 2層の高さがチャネルとドレインの高さになる。
- Bridge: 鋳型から PDMS を作る。

**P4 PDMS と接合**
- Topic: PDMS を鋳造してカバーガラスに接合する。
- Evidence: SYLGARD 184 を 10:1、真空脱泡 1 h、65 °C 12 h 以上。0.5 mm 生検トレパン（BP-A05F）で穴。エタノール超音波洗浄、65 °C 乾燥。カバーガラス（Neo No.1, Matsunami）は Contaminon LS-II 希釈液・超純水・エタノール・超純水で超音波洗浄、0.1 M NaOH、超純水、140 °C 乾燥。FA-1（Samco）で 10 s プラズマ処理して貼り合わせ。
- Implication: 流路は PDMS とカバーガラスで密閉され、カバーガラス側から観察する。
- Bridge: 日常の鋳造。

**P5 エポキシレプリカ**
- Topic: 日常の鋳造にはエポキシのレプリカを型にする。
- Evidence: 鋳型から PDMS のネガ型を取り、EA E-30CL（Loctite）を流して 24 h 以上硬化。図 fig:pdms_process。手順書（受け入れ条件・トラブル対応）は Appendix C。
- Implication: シリコンの鋳型を消耗させずに済む。
- Bridge: 細胞の準備と計測へ（2.7）。

## 2.7 細胞と長期タイムラプス計測

### 2.7.1 細胞株と培養条件

**P1 細胞株と培養条件**
- Topic: 野生型 FY18675 を使う。
- Evidence: NBRP から入手、h⁻。標準法（Moreno 1991）。YE 寒天の単一コロニー → EMM 2% グルコース 20 mL、30 °C 12 h → OD600 0.01 に希釈 → 50 mL チューブ（Watson）で 30 °C・200 rpm、OD600 0.2–0.5 まで。第3章 3.3.1 の HN0101 との対応は未確認（\mynote）。
- Implication: 指数増殖期の細胞をデバイスに入れる。
- Bridge: 計測の手順。

### 2.7.2 計測の手順

**P2 顕微鏡と環境**
- Topic: 計測は Ti-E 倒立顕微鏡で行う。
- Evidence: 40×/0.95 乾燥系（2.5）。ステージトップインキュベータ TIZHB（Tokai Hit）30 °C。PFS で焦点維持。Micro-Manager 1.4（Edelstein 2014）でステージ・シャッター・取得を制御。
- Implication: 温度と焦点が数日保たれる。
- Bridge: 細胞の導入。

**P3 細胞の準備と導入**
- Topic: 濃縮した培養液を注入し、重力で観察チャネルに入れる。
- Evidence: 20 mL を 3,700 rpm 5 min（himac CT6E）で 100 倍濃縮、1 mL シリンジ（Terumo）で注入、約 10 min 傾ける。旧本文の遠心 1,200 rpm 5 min × 2（180° 回転）とどちらが実験1の手順かは未確認（\mynote）。導入を確認後 2 mL/h で灌流、主流路の細胞がドレインから流れ去ってから計測開始。
- Implication: 観察チャネルの閉端に母細胞が入った状態から記録が始まる。
- Bridge: 灌流と培地交換。

**P4 培地交換と灌流**
- Topic: 流量は記録全長で 2 mL/h 一定。
- Evidence: PHD ULTRA（Harvard Apparatus）。培地交換はコネクタを含むチューブ一式ごと。交換時刻はコネクタ内の気泡が映った次のフレーム。
- Implication: 交換の時刻がフレーム単位で決まる。
- Bridge: 取得条件。

**P5 取得条件**
- Topic: 5 min 間隔、露光 60 ms。
- Evidence: 複数ステージ位置＋流路のない位置1つ（参照像の処理に使う）。性能評価の記録は約 168 h、2020 時点。
- Implication: 1記録で数千フレーム。
- Bridge: 蛍光像。

**P6 蛍光像の同時取得**
- Topic: Hsp104-GFP の記録では蛍光像を同時に取る。
- Evidence: 反対側のポート、LED（Thorlabs）、GFP キューブ（励起 460–500、DM 505、蛍光 510–560 nm）、ORCA-Fusion BT C14440（Hamamatsu）。
- Implication: 位相像と蛍光像が同じ時点で対応する。
- Bridge: 参照像をどう取るか（2.7.3）。第3章で使わないならこの段落は消す。

### 2.7.3 参照グリッドの取得

**P7 参照グリッドの取得**
- Topic: 計測前に各視野をステージ変位のグリッドで撮って参照像にする。
- Evidence: 9×9、0.1 µm 刻み。各変位で z スタックを撮り合焦面を残す。流路のない位置を同じ変位で撮った像を引く。中心像をフィードバックの基準にする。各時点で並進のみの位置合わせ（2.8.1）→ 測った変位でステージを更新 → 各視野は記録全長で ±0.4 µm 以内。記録後は各フレームに最も近い変位のグリッド像を対応させる（2.8.1）。
- Implication: 2.1.2 の条件 (4) を、細胞のそばに培地の領域が無いまま満たす。この章の新しい部分。
- Bridge: 画像解析へ（2.8）。

## 2.8 画像解析

**P0 処理の順**
- Topic: 位相像から乾燥質量密度までの処理は7段階。
- Evidence: 位置合わせ → 背景差分 → 培地屈折率の校正 → セグメンテーション → 系譜追跡 → 形状と体積 → 乾燥質量。
- Implication: 小節は3つ（位置合わせと背景差分／培地屈折率の校正／輪郭から乾燥質量まで）で、各小節に数段階が入る。
- Bridge: 位置合わせ。

### 2.8.1 位置合わせと背景差分

**P1 位置合わせ**
- Topic: 各時点の位相像をグリッド中心像に並進のみで合わせる。
- Evidence: ECC 最大化（Evangelidis 2008）、変換は並進のみ。計測中はその変位でステージを更新（2.7.3）。記録後は同じ方法で各フレームのグリッド中心からの変位を測る。コードは findTransformECC / MOTION_TRANSLATION。
- Implication: 変位が分かれば、どのグリッド像を引くかが決まる。
- Bridge: 背景差分。

**P2 背景差分**
- Topic: 最も近い変位のグリッド像を背景にして引く。
- Evidence: 残差の変位だけフレームをずらして重ねる。差は観察チャネルの周りに切った長方形の帯の中でとる。残る 2π の整数倍と線形の傾きは、帯のうち細胞の無い部分で推定して除く。空チャネルを引く旧方式のコードは残っていない。
- Implication: 参照像と試料像の変位の差はグリッド刻み（0.1 µm）以下に抑えられる。
- Bridge: 乾燥質量には培地の屈折率が要る。

### 2.8.2 培地屈折率の校正

**P3 培地屈折率の校正**
- Topic: BSA の濃度系列で培地の屈折率を校正する。
- Evidence: BSA 0–5% w/v（超純水）を順に灌流し、グリッドを撮った視野を各溶液で撮る。培地入りのグリッド中心像の位相を引き、チャネル上の位相の積分を濃度に最小二乗で直線当てはめ。傾き＝積分が見ている培地の体積、傾きと切片から n_medium。BSA の屈折率増分は配列から計算し、Zhao 2011 の波長・温度補正で 658 nm・30 °C の値。0% を最後に再測定して持ち越しとドリフトを確認。
- Implication: n_medium が式 eq:drymass に入る。直線性の結果は 2.9.3。
- Bridge: 細胞の輪郭。

### 2.8.3 細胞の輪郭・系譜・体積と乾燥質量

**P4 輪郭と系譜**
- Topic: Omnipose で輪郭を得て、マスクを面積でフレーム間に連結する。
- Evidence: 自前の画像から手で注釈した約 3,000 細胞で学習（Cutler 2022）。 各チャネルの閉端に最も近い細胞が起点。隣接2マスクの面積和が前フレームの1細胞と合えば分裂、閉端側が親の識別子を継ぐ。整合しないフレームは失敗の印。系譜＝閉端を占め続ける細胞の連なり。
- Implication: 1チャネル1系譜として、母細胞の密度を世代をまたいで追える。
- Bridge: 形状と体積。

**P5 細胞の形状と体積**
- Topic: 輪郭から長さ・幅・体積を出す。
- Evidence: 楕円 Fourier 記述子で平滑化 → medial axis → 軸に垂直な幅。長さ＝弧長、幅＝両端を除いた中央部の平均。体積＝回転対称を仮定した断面の積算。
- Implication: 体積 V が密度の分母になる。
- Bridge: 乾燥質量。

**P6 乾燥質量**
- Topic: Barer の式で乾燥質量濃度を求める。
- Evidence: C = (1/α)(n_medium − n_water + (λ/2πV)∬_S Δφ dA)。α = 0.18 mL/g（タンパク質・脂質・糖・核酸の平均、Barer 1954; Zangle 2014）。S は投影面積、Δφ は背景差分後の位相、λ = 658 nm、n_water = 1.3312。乾燥質量 = CV。α はコードの値に合わせる。

### 2.9.1 位相ノイズ

**P1 位相感度の理論**
- Topic: ショットノイズで制限された位相ノイズは、縞の visibility と電子数で決まる。
- Evidence: 式 eq:hologram_DH にノイズ項 z を加えて再構成すると φ' = φ + [z sin(k·r − φ) ∗ H]/|J^int|。分散の平方根から σ_φ'（eq:sigma_phi_DH）。ショットノイズでは Var(z) = Mean(I^DH)（eq:var_shot）。LP 帯域外の cos 項は ∗H で落ち、Σ H² = Σ h² · A_ap/A_sensor（eq:H_sum）。代入して σ^shot = √(J^non-int / 2|J^int|²) · √(A_ap/A_sensor)（eq:sigma_shot）。読み出しノイズを含めるなら分子に Var(z^sensor) を足す。V = 2|J^int|/J^non-int、N_e = J^non-int とおくと σ^shot = (1/(V√N_e)) √(2A_ap/A_sensor)。背景差分は独立な 2 計測の差なので √2 倍。
- Implication: σ_φ は V に反比例し、√N_e に反比例する。N_e の上限は full-well 容量（2.5）で決まるので、露光を固定したとき位相ノイズを決めるのは V。
- Bridge: 実測はどう測るか。

**P2 測り方**
- Topic: 時間方向の位相ノイズは、連続する 2 フレームの差から測る。
- Evidence: 細胞の無い領域で、連続フレームの位相像の差の空間標準偏差を √2 で割り、フレーム対で平均する。差をとるのは共通の背景を消すため、√2 は独立な 2 フレームの差の分散が 2 倍になるため。ショットノイズ限界は同じホログラムの visibility と強度から P1 の式で計算する。強度はカメラの変換ゲインで電子数に換算し、読み出しノイズは含めない。
- Implication: 実測と限界が同じホログラムから出るので、比がそのまま「ショットノイズ以外の寄与」になる。
- Bridge: 値。

**P3 結果**
- Topic: 実測の位相ノイズはショットノイズ限界の約 1.8 倍。
- Evidence: 実測 12.00 mrad、限界 6.68 mrad、比 1.80。λ = 658 nm では 1 mrad が光路長 0.105 nm。〔露光 200 ms・間隔 1 s の別データ。本番条件で測り直して差し替える。図は論文 Figure 3A に対応、修論の図は未作成〕
- Implication: 残りの約 0.8 倍分は読み出しノイズと機械的な揺らぎの寄与で、2.10 で扱う。
- Bridge: 位置合わせの精度（2.9.2）。
