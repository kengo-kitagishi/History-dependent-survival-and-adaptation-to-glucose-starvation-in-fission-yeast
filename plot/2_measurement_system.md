## 2.3 定量位相イメージングの原理
- 細胞と培地の屈折率差が光の位相遅れ Δφ(x) = (2π/λ)∫[n_cell − n_0]dz になる。センサは強度しか記録できないので位相を強度に変換する必要がある。位相差・DIC は定性、QPI は定量
- common-path 法は試料の後ろに干渉計を組むので振動・ずれに強く、顕微鏡の出力ポートに置ける。長期タイムラプス向き
- 角スペクトル法: Helmholtz 方程式の解を平面波の重ね合わせで書き、距離 d の伝搬は各成分に e^{ik_z d} を掛けること
- 対物レンズは NA/λ で切る帯域制限。Abbe 限界 Δx = λ/NA（コヒーレント照明）
- 4f 系: 2枚のレンズで物体面、Fourier 面、像面。1枚目が Fourier 変換、Fourier 面の空間フィルタで帯域を操作、2枚目で逆変換（倒立像）
- 干渉で位相を取り出す: I = |U_s + U_r|² の干渉項 U_s U_r* に位相が入る。on-axis では4項が Fourier 空間で重なって分離できない
- off-axis: 回折格子でキャリア波数 k^off を物体光に与え、ピンホールで参照光を準平面波にする。干渉項が Fourier 空間で分離し、+1 次サイドバンドから U_s を取り出せる
- ホログラムの式: I^DH = J^non-int + J^int e^{−i k·r} + c.c.（記号は 3/1 に U 系へ統一済み）

決めること: 4f の図 fig:4f_system が無い。本文に残すのは、位相と OPD の関係、ホログラムの式と off-axis で干渉項が分離する理由、カットオフ NA/λ とサンプリング条件の3つ。角スペクトル法・単レンズの Fourier 変換・4f の伝搬・defocus の許容は Appendix A へ（9/12 の予定）。

## 2.4 位相像の再構成
- 再構成は (1) 2D FT、(2) サイドバンドの中心化、(3) 半径 r = (2πNA/λ)·N·Δp の円形 LP、(4) 2D IFT、そのあと背景で割る。OPD = φλ/2π
- 空間分解能と Fourier 面のパラメータ: f_cutoff = NA/λ、開口径 D_ap = 2⌊(NA/λ)·FOV⌋+1、再構成画素 Δp_recon = FOV/D_ap ≈ λ/2NA
- 2段階のサンプリング条件: 生ホログラムは Nyquist（Δp < λ/2NA、2–4倍のオーバーサンプリング）、再構成像は1分解能要素 ≈ 2画素
- 我々の値: λ = 658 nm、NA 0.95、40×、画素 3.45 µm。Δp = 86.25 nm、FOV 176.6 µm、Abbe 692 nm、Nyquist 346 nm、オーバーサンプリング 4.0×、D_ap = 511、Δp_recon = 346 nm

## 2.5 光学系
- 設計条件2つ: (i) 干渉項と非干渉項が Fourier 空間で重ならない k^off ≥ 3·(2πNA/λM)、(ii) 干渉項が Nyquist を超えない k^off/√2 + 2πNA/λM ≤ πf_pitch。合わせて 6.80×10⁵ ≤ k^off ≤ 9.68×10⁵ rad/m
- 構成: 658 nm LD（LP660-SF20）、コリメータ、試料、40×/0.95、Ronchi 格子 120 lp/mm、4f リレー（f = 200 mm）、Fourier 面の 25 µm ピンホールで0次を参照光に、1次を物体光に、Basler acA2440-75（2448×2048、3.45 µm）。生ホログラム 2048×2048、OPD 像 511×511
- 格子から決まる k^off = 2π/8.33 µm = 7.54×10⁵ rad/m は両条件を満たす
- 検証: 実測サイドバンド位置 (1623, 1621)、中心からのずれ (599, 597) 画素、Δf = 1/(2048×3.45 µm) から k_exp = 7.53×10⁵ rad/m。理論値 7.54×10⁵ と一致
