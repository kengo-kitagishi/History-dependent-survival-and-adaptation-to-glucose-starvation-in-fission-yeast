# 第2章 QPIによる長期1細胞計測系の構築 — plot

## 2.1 背景

### 2.1.1 細胞質の乾燥質量密度と既存の計測法
- P1 密度は拡散・反応速度・相分離に影響する。集団平均では増殖速度によらず一定だが、1細胞では生合成と体積成長が脱共役しうる。それでも同一条件の細胞間の差は数% → 第3章の問いには、数%の差を分解する精度で同じ細胞を数日測る計測が要る
- P2 屈折率は分子濃度の指標。n = n0 + αC、α はタンパク質・核酸でほぼ共通で線形 → 屈折率差から乾燥質量濃度が求まる
- P3 1細胞の密度計測法（浮遊密度・SMR・蛍光排除法・ラマン）は、それぞれ 同じ細胞の時系列が取れない／数日追えない／色素が要る／取得に時間がかかる
- P4 QPI は1枚露光・無標識で位相から乾燥質量を与え、長期タイムラプスに使える。分裂酵母でも周期内の密度変動は測られているが、系譜に沿った記録は1〜数周期どまり

### 2.1.2 長期1細胞密度計測系の必要条件
- P5 必要条件は4つ: (1) 長期の1細胞追跡 (2) 1枚露光・無標識・common-path (3) 位相ノイズが密度差に対応する位相差より小さい (4) 背景を細胞のない領域から取れる
- P6 (1)(2) は既存要素の組み合わせで満たせる。(3) は設計と性能評価で示す。(4) は既存法では満たせないので参照グリッドを導入する

決めること: P1 の入り方（生物学から入るか、既存技術から入るか。第1章との重なり）／P3 で比べる方法の範囲（ODT を入れるか）／必要条件 (3) に具体値を置くか／P4 の終わりを「飢餓下で数日追える計測が無い」に寄せるか／屈折率増分は文献値 0.18〜0.19 と書き、解析で使う1つの値は 2.8.7 で決める

## 2.2 目的
- P1 2.1.2 の4条件を満たす計測系を作る: common-path off-axis DH ＋ mother machine ＋ 参照グリッド ＋ 解析パイプライン。性能は 2.9 で示し、第3章で使う

## 2.3 定量位相イメージングの原理
- 細胞と培地の屈折率差が光の位相遅れ Δφ(x) = (2π/λ)∫[n_cell − n_0]dz になる。センサは強度しか記録できないので位相を強度に変換する必要がある。位相差・DIC は定性、QPI は定量
- common-path 法は試料の後ろに干渉計を組むので振動・ずれに強く、顕微鏡の出力ポートに置ける。長期タイムラプス向き
- 角スペクトル法: Helmholtz 方程式の解を平面波の重ね合わせで書き、距離 d の伝搬は各成分に e^{ik_z d} を掛けること
- 対物レンズは NA/λ で切る帯域制限。Abbe 限界 Δx = λ/NA（コヒーレント照明）
- 4f 系: 2枚のレンズで物体面、Fourier 面、像面。1枚目が Fourier 変換、Fourier 面の空間フィルタで帯域を操作、2枚目で逆変換（倒立像）
- 干渉で位相を取り出す: I = |U_s + U_r|² の干渉項 U_s U_r* に位相が入る。on-axis では4項が Fourier 空間で重なって分離できない
- off-axis: 回折格子でキャリア波数 k^off を物体光に与え、ピンホールで参照光を準平面波にする。干渉項が Fourier 空間で分離し、+1 次サイドバンドから U_s を取り出せる
- ホログラムの式: I^DH = J^non-int + J^int e^{−i k·r} + c.c.

決めること: Appendix A（4f 系の理論導出）は廃止した。本文に残すのは、位相と OPD の関係、ホログラムの式と off-axis で干渉項が分離する理由、カットオフ NA/λ とサンプリング条件の3つ。角スペクトル法・単レンズの Fourier 変換・4f の伝搬（fig:4f_system の参照を含む）は消す（git に残る）

## 2.4 位相像の再構成
- P1 再構成は5段階: 2D FT → +1次サイドバンドを原点へ移す → 半径 (NA/λ)·N·Δp の円窓で切る → 2D IFT で複素場、その arg が位相 → reliability-ordered 法で unwrap。図 fig:reconstruction
- P2 背景の除去: 同じ視野の細胞のない位相像（参照像）を引く。式は複素場の比の arg。参照像の取り方は 2.7.6、どれを引くかは 2.8.2。以降は位相 φ で扱い OPD は1文
- P3 分解能と Fourier 面のパラメータ: f_cutoff = NA/λ、円窓の直径 D_ap = 2·round((NA/λ)·FOV)+1 が位相像の画素数、Δp_recon = FOV/D_ap ≈ λ/2NA
- P4 サンプリング条件は2段階: 生ホログラムは Nyquist（Δp < λ/2NA、2〜4倍の余裕）、位相像は1分解能要素 ≈ 2画素。生側の余裕は 2.5 の設計条件 (ii) と同じ要求
- P5 我々の値: λ = 658 nm、NA 0.95、40×、画素 3.45 µm → Δp = 86.25 nm、FOV 176.64 µm、Abbe 692 nm、Nyquist 346 nm、余裕 4.0 倍、(NA/λ)·FOV = 255.0、D_ap = 511、Δp_recon = 346 nm

## 2.5 光学系
- P1 設計条件は2つ: (i) 干渉項と非干渉項が Fourier 空間で重ならない k^off ≥ 3·(2πNA/λM)、(ii) 干渉項が Nyquist を超えない k^off/√2 + 2πNA/λM ≤ πf_pitch。我々の NA・M・画素では 6.80×10⁵ ≤ k^off ≤ 9.68×10⁵ rad/m
- P2 構成: 658 nm LD → コリメータ → 試料 → 40×/0.95 → 像面の Ronchi 格子 120 lp/mm → 4f リレー（f = 200 mm）→ Fourier 面の 25 µm ピンホールで 0 次を参照光、1 次を物体光 → CMOS（2448×2048、3.45 µm、FWC ≈ 10 ke⁻）。生ホログラム 2048×2048。図 1A
- P3 格子から決まる k^off = 2π/8.33 µm = 7.54×10⁵ rad/m は P1 の範囲に入る
- P4 検証: 実測のサイドバンド位置 (1623, 1621)、中心からのずれ (599, 597) 画素、Δf = 1/(2048 × 3.45 µm) = 141.5 m⁻¹ から k_exp = 7.53×10⁵ rad/m。理論値と一致

## 2.6 マイクロ流路デバイス
- mother machine の原理: 主流路に垂直な行き止まりの細い成長チャネルに細胞を1列で閉じ込め、母細胞を長期に追う。培地は拡散で秒スケールで届く。娘細胞は流れで洗い出される（Wang 2010）
- 我々のデバイス: 主流路幅 180 µm、観察チャンバー幅 ≈6.3 µm・長さ ≈40 µm、シリンジポンプで一方向に灌流
- 作製: マスクレス露光でフォトマスク、SU-8 2層（観察チャネル層 SU-8 2/3005、3,000 rpm；ドレイン層 SU-8 3010、1,500 rpm）、PDMS（SYLGARD 184、10:1）、0.5 mm パンチ、カバーガラス洗浄（Contaminon、NaOH）、プラズマ接合（FA-1、10 s）
- エポキシレプリカ: PDMS のネガ型から LOCTITE EA E-30CL で複製し、日常の鋳造の型にする
- 手順書（受け入れ条件・トラブル対応つき）は Appendix C

決めること: 図（構造の模式図・観察チャネル・作製工程）は Figure 1B に差し替える／デバイス寸法（180 / 6.3 / 40 µm）と論文の「Nakaoka & Wakamoto の寸法」が同じか、QPI_Omni か設計図で確認／mother machine の原理は大腸菌向けの日本語 1477 字を 1〜2 段落に縮める

## 2.7 細胞と長期タイムラプス計測
- 顕微鏡と環境: Ti-E 倒立、40×/0.95 空気、ステージトップインキュベータ（TIZHB, Tokai Hit）30 °C、PFS、Micro-Manager 1.4
- 細胞株と培養条件: 性能評価に使った記録の株と培地。第3章 3.3.1 と同じなら1段落で再掲
- 細胞の準備と導入: EMM 2% glucose 指数増殖期 20 mL、3,700 rpm 5 min で 100 倍濃縮、1 mL シリンジで導入、1,200 rpm 5 min を 180° 回して2回、2 mL/h で灌流し余分な細胞を流す
- 培地交換: チューブとコネクタごと交換。コネクタ内の気泡が映った次のフレームを交換時刻にする
- 灌流: シリンジポンプ（Harvard ULTRA-P）で 2 mL/h 一定
- 取得条件: 5 分間隔、露光 60 ms、複数ステージ位置＋流路のない位置1つ
- 参照グリッドの取得: 細胞のそばに培地だけの領域が残らないので、計測前に stage 変位の 9×9 グリッド（0.1 µm 刻み）で参照像を撮る。中心像を計測中のフィードバックの基準にし、各視野を記録全長で ±0.4 µm 以内に保つ

決めること: 実験1の株（HN0101 か FY18675 か）／3本の記録（EMM 2%／YE／YE Hsp104-GFP）のうち 2.9 は EMM 2% の1本で書く／旧「タイムラプス計測と画像の取得」（蛍光顕微鏡の記述）は Hsp104-GFP を第3章で使うなら 3.3 へ、使わないなら消す／細胞の導入は遠心（修論）と重力で傾ける（論文）のどちらが実験1の手順か

## 2.8 画像解析
- 位置合わせ: 各時点で ECC（並進のみ）で参照像に合わせ、測った変位からステージを戻す
- 背景差分: 各フレームの変位に最も近いグリッド像を背景として引く。残る 2π の倍数と線形成分は細胞のない領域で推定して除く
- 培地屈折率の校正: BSA 濃度系列（0–5% w/v）の灌流。位相の和を濃度に対して最小二乗で当てはめ、傾きと切片から培地の屈折率
- セグメンテーション: Omnipose を自前の約 3000 細胞で学習
- 系譜追跡: 面積でフレーム間を連結。分裂は隣接2マスクの面積和で判定、閉端側が親の識別子を継ぐ
- 細胞の形状と体積: 楕円 Fourier 記述子で輪郭を平滑化し、medial axis に垂直な幅から回転対称で体積
- 乾燥質量: Barer (1952)、屈折率増分 α、位相の面積分と体積から乾燥質量濃度 C。乾燥質量は CV

決めること: 位置合わせは「空チャネルを引く」旧方式か「グリッド像を引く」方式か、今のコードを QPI_Omni で確認／旧 Image analysis・Image Preprocessing の段落は別論文の手順の写しなので置き換える

## 2.9 性能評価
- 位相感度の理論: ノイズ項 z を加えた再構成 φ' の分散から σ_φ = (1/V)√(2/N_e)·√(A_ap/A_sensor)。背景差分で √2 倍。V^{-1} と N_e^{-1/2} に依存
- 位相ノイズ: 連続フレーム差の空間標準偏差/√2 を細胞のない領域で測り、上の shot-noise 限界と比べる（Figure 3A）
- 参照グリッド登録の精度: 公称ステージ変位と実測変位の差、誤差ベクトル（Figure 3B）
- ドリフト: 記録全長での位置ずれ、補正あり／なし（Figure 3C）
- 既知シフトの回収: 細胞のない領域に既知の sub-pixel 並進を与えて回収、MAE 3.8 nm（Figure 3D）
- 濃度校正の直線性: BSA 系列に対する位相の線形（Figure 2）
