# 第2章 QPIによる長期1細胞計測系の構築 — plot

## 2.1 背景

### 2.1.1 細胞質の乾燥質量密度と既存の計測法
- P1 密度は拡散・反応速度・相分離に影響する。集団平均では増殖速度によらず一定だが、1細胞では生合成と体積成長が脱共役しうる。それでも同一条件の細胞間の差は数% → 第3章の問いには、数%の差を分解する精度で同じ細胞を数日測る計測が要る
- P2 屈折率は分子濃度の指標。n = n0 + αC、α はタンパク質・核酸でほぼ共通で線形 → 屈折率差から乾燥質量濃度が求まる
- P3 1細胞の密度計測法（浮遊密度・SMR・蛍光排除法・ラマン）は、それぞれ 同じ細胞の時系列が取れない／数日追えない／色素が要る／取得に時間がかかる
- P4 QPI は1枚露光・無標識で位相から乾燥質量を与え、長期タイムラプスに使える。分裂酵母でも周期内の密度変動は測られているが、系譜に沿った記録は1〜数周期どまり

### 2.1.2 長期1細胞密度計測系の必要条件
- P5 必要条件は4つ: (1) 長期の1細胞追跡 (2) 1枚露光・無標識・common-path (3) 位相ノイズが密度差に対応する位相差より小さい (4) 背景を細胞のない領域から取れる
- P6 (1)(2) は既存要素の組み合わせで満たせる。(3) は設計と性能評価で示す。(4) は既存法では満たせないので参照グリッドを導入する

決めること: P1 の入り方（生物学から入るか、既存技術から入るか。第1章との重なり）／P3 で比べる方法の範囲（ODT を入れるか）／必要条件 (3) に具体値を置くか／P4 の終わりを「飢餓下で数日追える計測が無い」に寄せるか／屈折率増分は文献値 0.18〜0.19 と書き、解析で使う1つの値は 2.8.3 で決める

## 2.2 目的
- P1 2.1.2 の4条件を満たす計測系を作る: common-path off-axis DH ＋ mother machine ＋ 参照グリッド ＋ 解析パイプライン。性能は 2.9 で示し、第3章で使う

## 2.3 定量位相イメージングの原理

### 2.3.1 位相遅れと共通光路法
- P1 細胞と培地の屈折率差が位相遅れ Δφ(x) = (2π/λ)∫[n_cell − n_0]dz になる。センサは強度しか記録できない。位相差・DIC は定性、QPI は定量
- P2 common-path 法は試料の後ろに干渉計を組み、2光が素子を共有する → 振動・ずれに強く、顕微鏡の出力ポートに組める。長期タイムラプス向き

### 2.3.2 対物レンズによる帯域制限
- P3 対物レンズは NA/λ で切る帯域制限。Abbe 限界 Δx = λ/NA（コヒーレント照明）

### 2.3.3 オフアクシス干渉による位相の回復
- P4 干渉で位相を取り出す: I = |U_s + U_r|² の干渉項 U_s U_r* に位相が入る。on-axis では4項が Fourier 空間で重なって分離できない
- P5 off-axis: 格子でキャリア波数 k^off を物体光に与え、ピンホールで参照光を準平面波にする。ホログラムの式 I^DH = J^non-int + J^int e^{−i k·r} + c.c.
- P6 Fourier 変換で3成分が原点と ±k^off に分かれ、+1次サイドバンドから U_s と位相が取れる → 2.4 で再構成

## 2.4 位相像の再構成
- P1 再構成は5段階: 2D FT → +1次サイドバンドを原点へ移す → 半径 (NA/λ)·N·Δp の円窓で切る → 2D IFT で複素場、その arg が位相 → reliability-ordered 法で unwrap。図 fig:reconstruction
- P2 背景の除去: 同じ視野の細胞のない位相像（参照像）を引く。式は複素場の比の arg。参照像の取り方は 2.7.3、どれを引くかは 2.8.1。以降は位相 φ で扱い OPD は1文
- P3 分解能と Fourier 面のパラメータ: f_cutoff = NA/λ、円窓の直径 D_ap = 2·round((NA/λ)·FOV)+1 が位相像の画素数、Δp_recon = FOV/D_ap ≈ λ/2NA
- P4 サンプリング条件は2段階: 生ホログラムは Nyquist（Δp < λ/2NA、2〜4倍の余裕）、位相像は1分解能要素 ≈ 2画素。生側の余裕は 2.5 の設計条件 (ii) と同じ要求
- P5 本研究の値: λ = 658 nm、NA 0.95、40×、画素 3.45 µm → Δp = 86.25 nm、FOV 176.64 µm、Abbe 692 nm、Nyquist 346 nm、余裕 4.0 倍、(NA/λ)·FOV = 255.0、D_ap = 511、Δp_recon = 346 nm

## 2.5 光学系

### 2.5.1 設計条件
- P1 何を決める節か: k^off（= 2π/縞の周期）をどこに置くかで位相が取り出せるかが決まる。小さすぎると干渉項が非干渉項と重なり、大きすぎると縞が画素より細かくてセンサが記録できない。下限と上限は NA・倍率・画素ピッチだけで決まる
- P2 下限（重なり）: 対物が NA/λ で切るので試料の情報は半径 2πNA/(λM) の円板で尽き、その外は雑音だけ。干渉項も同じ半径、非干渉項は自己相関で2倍。中心の間隔が半径の和を超える条件が k^off ≥ 3·(2πNA/λM)
- P3 上限（Nyquist）: 円板の最も高い周波数が Nyquist（f_pitch の半分）以下。限界は各軸ごとなので、キャリアを対角方向に置くと各軸の成分が k^off/√2 に下がり有利。本研究の格子はこの向き。k^off/√2 + 2πNA/(λM) ≤ πf_pitch
- P4 本研究の範囲: NA 0.95、M 40、λ 658 nm、画素 3.45 µm → 6.80×10⁵ ≤ k^off ≤ 9.68×10⁵ rad/m

### 2.5.2 構成
- P2 構成: 658 nm LD → コリメータ → 試料 → 40×/0.95 → 像面の Ronchi 格子 120 lp/mm → 4f リレー（f = 200 mm）→ Fourier 面の 25 µm ピンホールで 0 次を参照光、1 次を物体光 → CMOS（2448×2048、3.45 µm、FWC ≈ 10 ke⁻）。生ホログラム 2048×2048。図 1A

### 2.5.3 オフアクシス配置の検証
- P3 格子から決まる k^off = 2π/8.33 µm = 7.54×10⁵ rad/m は P1 の範囲に入る
- P4 検証: 実測のサイドバンド位置 (1623, 1621)、中心からのずれ (599, 597) 画素、Δf = 1/(2048 × 3.45 µm) = 141.5 m⁻¹ から k_exp = 7.53×10⁵ rad/m。理論値と一致

## 2.6 マイクロ流路デバイス

### 2.6.1 mother machine の原理
- P1 mother machine の原理: 主流路に垂直な行き止まりの観察チャネルに細胞を1列で閉じ込め、閉端の母細胞を長期に追う。娘細胞は流れで洗い出される。培地は拡散で秒の桁で届く。培地の切り替えで環境を変えられる。分裂酵母でも使われている（Wang 2010; Nakaoka 2017）。図 fig:mm_schematic

### 2.6.2 デバイスの構成
- P2 本研究のデバイス: Nakaoka 2017 の設計に倣って自作。観察チャネル 幅 5.3 µm × 高さ 6.2 µm、主流路（ドレイン）幅 214 µm × 高さ 19.75 µm。2層の SU-8。シリンジポンプで 2 mL/h。図 fig:mm_layout

### 2.6.3 作製
- P3 鋳型: マスクレス露光でフォトマスク2枚、SU-8 2層（観察チャネル層 SU-8 2/3005 3000 rpm、5 s × 3 露光；ドレイン層 SU-8 3010 1500 rpm、30 s 露光）

- P5 エポキシレプリカ: PDMS のネガ型から EA E-30CL で複製し、日常の鋳造の型にする。手順書は Appendix C。図 fig:pdms_process

## 2.7 細胞と長期タイムラプス計測

### 2.7.1 細胞株と培養条件
- P1 細胞株と培養条件: 野生型 FY18675（NBRP）。YE 寒天 → EMM 2% 20 mL 12 h → OD 0.01 に希釈 → 200 rpm で OD 0.2–0.5

### 2.7.2 計測の手順
- P2 顕微鏡と環境: Ti-E 倒立、2.5 の 40×/0.95、ステージトップインキュベータ（TIZHB）30 °C、PFS、Micro-Manager 1.4
- P3 細胞の準備と導入: 20 mL を 3,700 rpm 5 min で 100 倍濃縮、1 mL シリンジで注入、傾けて約 10 min 重力で導入、2 mL/h で灌流し余分な細胞を流す
- P4 培地交換と灌流: PHD ULTRA で 2 mL/h 一定。交換はチューブとコネクタごと。交換時刻はコネクタ内の気泡が映った次のフレーム
- P5 取得条件: 5 min 間隔、露光 60 ms、複数ステージ位置＋流路のない位置1つ。性能評価の記録は約 168 h（2020 時点）
- P6 蛍光像の同時取得: Hsp104-GFP の記録では反対側ポートから LED・GFP キューブ・ORCA-Fusion BT で同時取得

### 2.7.3 参照グリッドの取得

## 2.8 画像解析
- P0 処理の順: 位置合わせ → 背景差分 → 培地屈折率の校正 → セグメンテーション → 系譜追跡 → 形状と体積 → 乾燥質量

### 2.8.1 位置合わせと背景差分
- P1 位置合わせ: 各時点の位相像をグリッド中心像に ECC（並進のみ）で合わせる。計測中はステージ更新、記録後は各フレームの変位の計測
- P2 背景差分: 最も近い変位のグリッド像を背景にし、残差だけずらして、観察チャネル周りの帯で差をとる。残る 2π の整数倍と線形の傾きは細胞のない部分で推定して除く

### 2.8.2 培地屈折率の校正
- P3 培地屈折率の校正: BSA 0–5% w/v の系列を灌流、グリッド中心像を引いた位相の積分を濃度に直線当てはめ。傾き＝見ている培地の体積、傾きと切片から n_medium。BSA の屈折率増分は配列から計算し Zhao 2011 の波長・温度補正。0% を最後に再測定

### 2.8.3 細胞の輪郭・系譜・体積と乾燥質量
- P4 輪郭と系譜: Omnipose を自前の約 3,000 細胞で学習。マスクを面積で連結、閉端の細胞が起点。隣接2マスクの面積和が前フレームの1細胞と合えば分裂、閉端側が親の識別子を継ぐ。失敗は印。系譜＝閉端を占め続ける細胞の連なり
- P5 形状と体積: 楕円 Fourier 記述子で平滑化 → medial axis → 垂直な幅。長さ＝弧長、幅＝中央部の平均。体積は回転対称で断面を積算
- P6 乾燥質量: C = (1/α)(n_medium − n_water + (λ/2πV)∬Δφ dA)、α = 0.18 mL/g、n_water = 1.3312。乾燥質量 = CV

決めること: α はコードの値に合わせる（2.1 の文献値 0.18〜0.19 と整合させる）

## 2.9 性能評価
- P0 この節で示すこと: 2.1.2 の条件 (3)（位相ノイズが密度差に対応する位相差より小さい）と (4)（参照像をグリッドから取れる）が、本番の記録（260517、EMM 2%、先頭 168.25 h = 2020 フレーム、5 分間隔、露光 60 ms、104 視野）で満たされている。数値と図は論文の Figure 2・3 と共通

### 2.9.1 位相ノイズ
- P1 理論: ホログラムにノイズ項 z を加えて再構成すると、位相の標準偏差は σ_φ = (1/V)√(2/N_e)·√(A_ap/A_sensor)（V: 縞の visibility、N_e: 電子数、A_ap/A_sensor: 円窓の画素数とセンサ画素数の比）。背景差分で √2 倍。σ_φ ∝ V⁻¹、N_e^{−1/2}
- P2 測り方: 細胞のない領域で連続フレームの差の空間標準偏差を √2 で割り、フレーム対で平均する。shot-noise 限界は同じホログラムの visibility と強度（変換ゲインで電子数に換算。読み出しノイズは含めない）から計算する
- P3 結果: 実測 12.00 mrad、shot-noise 限界 6.68 mrad、比 1.80（λ = 658 nm で 1 mrad は光路長 0.105 nm）。図 3A〔この値は露光 200 ms・間隔 1 s の別データ。本番条件（60 ms・5 分）で測り直す〕

### 2.9.2 位置合わせの精度と長期のドリフト
- P4 既知シフトの回収: 観察チャネル帯に ±0.69 µm（±2 画素）の既知の並進を 2200 回 × 2 軸で注入し、32 bit 実数経路の ECC で回収した。MAE 3.8 nm（約 1/90 画素、グリッド刻み 0.1 µm の 1/25）、バイアス X −0.3 nm、Y −1.9 nm。8 bit 経路は X に 0.125 画素のバイアスが出るので使わない。図 3D
- P5 参照グリッドの登録: 81 ノードの公称ステージ変位と ECC で測った実測変位の対応、各ノードの誤差ベクトル。走査の向きが反転する軸で、行の偶奇で交代するオフセットが見える。図 3B〔対応表を 32 bit 実数で作り直してから。9/13 の校正セッションで同時に撮るグリッドで作る〕
- P6 ドリフト: フィードバックありの本番記録で、各視野のグリッド中心からの変位は 13 日間を通して中央値 0.11–0.14 µm、95% 点 0.25–0.32 µm、0.4 µm 以内が 98–99.6%。補正なしの累積変位は残差の累積和で復元でき、y 方向に約 3.5 µm/日でグリッドの範囲を超える。図 3C

### 2.9.3 参照グリッドによる背景差分の残差
- P7 細胞のない観察チャネル帯 6 本・1434 測定で、参照像をそのフレームの変位まで動かした量に対する残差の標準偏差は、0.1 µm 未満で 64 mrad、0.4–0.7 µm で 94 mrad、1.5–3 µm で 563 mrad。残差は参照を動かした距離で決まり、方法（平行移動か最近傍ノードか）では決まらない。実測した参照像が近くにあれば残差は測定床にとどまる。図 2
- P8 残差を乾燥質量に換算すると（細胞マスクに一様に乗る最悪ケース、α = 0.18 mL/g、投影面積 35 µm²）1.3 pg／1.9 pg／11.5 pg。563 mrad は細胞 1 世代分の成長に相当し、グリッドなしでは密度の時系列が読めない

### 2.9.4 培地屈折率の校正と密度の測定限界
- P9 BSA 濃度系列に対する積算位相の直線性: 傾きが校正体積、切片が水と培地の屈折率差、0% の再測定で持ち越しとドリフトを確認する。図 3E–G〔9/13 10:00 に撮影。まだ数値なし。2 液法（水・エタノール）の暫定値は n(2%) = 1.336288 ± 0.000715（4/25）と 1.335029 ± 0.000109（4/26）。視野が独立でないので不確かさは移動ブロックブートストラップ〕
- P10 誤差の伝播: 位相ノイズ・背景差分の残差・体積・屈折率校正の各誤差を式 eq:drymass に伝播した密度の測定床（1σ）を、周期平均密度の分布（CV 5.9%）と同じ軸に重ねる。分布の幅が測定床より広いことがこの章の結論で、第3章の前提になる。図 3H〔未作成。66 チャネルの per-cell データから〕
