# 第2章 QPIによる長期1細胞計測系の構築 — plot

## 2.1 背景

### 2.1.1 細胞質の乾燥質量密度と既存の計測法
- P1 密度は拡散・反応速度・相分離に影響する。集団平均では増殖速度によらず一定だが、1細胞では生合成と体積成長が脱共役しうる。それでも同一条件の細胞間の差は数% → 第3章の問いには、数%の差を分解する精度で同じ細胞を数日測る計測が要る
- P2 屈折率は分子濃度の指標。n = n0 + αC、α はタンパク質・核酸でほぼ共通で線形 → 屈折率差から乾燥質量濃度が求まる
- P3 1細胞の密度計測法（浮遊密度・SMR・蛍光排除法・ラマン）は、それぞれ 同じ細胞の時系列が取れない／数日追えない／色素が要る／取得に時間がかかる
- P4 QPI は1枚露光・無標識で位相から乾燥質量を与え、長期タイムラプスに使える。分裂酵母でも周期内の密度変動は測られているが、系譜に沿った記録は1〜数周期どまり

### 2.1.2 長期1細胞密度計測系の必要条件
- P5 必要条件は4つ: (1) 長期の1細胞追跡 (2) 1枚露光・無標識・common-path (3) 位相ノイズが密度差に対応する位相差より小さい (4) 背景を細胞のない領域から取れる
- P6 (1)(2) は既存要素の組み合わせで満たせる。(3) は設計と性能評価で示す。(4) は既存法では満たせないので参照グリッドを導入する

決めること: P1 の入り方（生物学から入るか、既存技術から入るか。第1章との重なり）／P3 で比べる方法の範囲（ODT を入れるか）／必要条件 (3) に具体値を置くか／P4 の終わりを「飢餓下で数日追える計測が無い」に寄せるか／屈折率増分は文献値 0.18〜0.19 と書き、解析で使う1つの値は 2.8.7 で決める

## 2.2 目的
- P1 2.1.2 の4条件を満たす計測系を作る: common-path off-axis DH ＋ mother machine ＋ 参照グリッド ＋ 解析パイプライン。性能は 2.9 で示し、第3章で使う

## 2.3 定量位相イメージングの原理
- P1 細胞と培地の屈折率差が位相遅れ Δφ(x) = (2π/λ)∫[n_cell − n_0]dz になる。センサは強度しか記録できない。位相差・DIC は定性、QPI は定量
- P2 common-path 法は試料の後ろに干渉計を組み、2光が素子を共有する → 振動・ずれに強く、顕微鏡の出力ポートに組める。長期タイムラプス向き
- P3 対物レンズは NA/λ で切る帯域制限。Abbe 限界 Δx = λ/NA（コヒーレント照明）
- P4 干渉で位相を取り出す: I = |U_s + U_r|² の干渉項 U_s U_r* に位相が入る。on-axis では4項が Fourier 空間で重なって分離できない
- P5 off-axis: 格子でキャリア波数 k^off を物体光に与え、ピンホールで参照光を準平面波にする。3成分が分離し、+1次サイドバンドから U_s が取れる
- P6 ホログラムの式: I^DH = J^non-int + J^int e^{−i k·r} + c.c. → 2.4 で再構成

## 2.4 位相像の再構成
- P1 再構成は5段階: 2D FT → +1次サイドバンドを原点へ移す → 半径 (NA/λ)·N·Δp の円窓で切る → 2D IFT で複素場、その arg が位相 → reliability-ordered 法で unwrap。図 fig:reconstruction
- P2 背景の除去: 同じ視野の細胞のない位相像（参照像）を引く。式は複素場の比の arg。参照像の取り方は 2.7.6、どれを引くかは 2.8.2。以降は位相 φ で扱い OPD は1文
- P3 分解能と Fourier 面のパラメータ: f_cutoff = NA/λ、円窓の直径 D_ap = 2·round((NA/λ)·FOV)+1 が位相像の画素数、Δp_recon = FOV/D_ap ≈ λ/2NA
- P4 サンプリング条件は2段階: 生ホログラムは Nyquist（Δp < λ/2NA、2〜4倍の余裕）、位相像は1分解能要素 ≈ 2画素。生側の余裕は 2.5 の設計条件 (ii) と同じ要求
- P5 我々の値: λ = 658 nm、NA 0.95、40×、画素 3.45 µm → Δp = 86.25 nm、FOV 176.64 µm、Abbe 692 nm、Nyquist 346 nm、余裕 4.0 倍、(NA/λ)·FOV = 255.0、D_ap = 511、Δp_recon = 346 nm

## 2.5 光学系
- P1 設計条件は2つ: (i) 干渉項と非干渉項が Fourier 空間で重ならない k^off ≥ 3·(2πNA/λM)、(ii) 干渉項が Nyquist を超えない k^off/√2 + 2πNA/λM ≤ πf_pitch。我々の NA・M・画素では 6.80×10⁵ ≤ k^off ≤ 9.68×10⁵ rad/m
- P2 構成: 658 nm LD → コリメータ → 試料 → 40×/0.95 → 像面の Ronchi 格子 120 lp/mm → 4f リレー（f = 200 mm）→ Fourier 面の 25 µm ピンホールで 0 次を参照光、1 次を物体光 → CMOS（2448×2048、3.45 µm、FWC ≈ 10 ke⁻）。生ホログラム 2048×2048。図 1A
- P3 格子から決まる k^off = 2π/8.33 µm = 7.54×10⁵ rad/m は P1 の範囲に入る
- P4 検証: 実測のサイドバンド位置 (1623, 1621)、中心からのずれ (599, 597) 画素、Δf = 1/(2048 × 3.45 µm) = 141.5 m⁻¹ から k_exp = 7.53×10⁵ rad/m。理論値と一致

決めること: 図は3月版か 8/14 版（論文 Figure 1A）か／部品の型番をどこまで書くか（光学素子は残し、LD ドライバとケーブルは落とす案）

## 2.6 マイクロ流路デバイス
- P1 mother machine の原理: 主流路に垂直な行き止まりの観察チャネルに細胞を1列で閉じ込め、閉端の母細胞を長期に追う。娘細胞は流れで洗い出される。培地は拡散で秒の桁で届く。培地の切り替えで環境を変えられる。分裂酵母でも使われている（Wang 2010; Nakaoka 2017）。図 fig:mm_schematic
- P2 我々のデバイス: Nakaoka 2017 の設計に倣って自作。観察チャネル 幅 5.3 µm × 高さ 6.2 µm、主流路（ドレイン）幅 214 µm × 高さ 19.75 µm。2層の SU-8。シリンジポンプで 2 mL/h。図 fig:mm_layout
- P3 鋳型: マスクレス露光でフォトマスク2枚、SU-8 2層（観察チャネル層 SU-8 2/3005 3000 rpm、5 s × 3 露光；ドレイン層 SU-8 3010 1500 rpm、30 s 露光）
- P4 PDMS と接合: SYLGARD 184 10:1、脱泡 1 h、65 °C 12 h 以上、0.5 mm パンチ、カバーガラス洗浄（Contaminon、NaOH）、プラズマ接合（FA-1、10 s）
- P5 エポキシレプリカ: PDMS のネガ型から EA E-30CL で複製し、日常の鋳造の型にする。手順書は Appendix C。図 fig:pdms_process

決めること: 観察チャネルの長さ・間隔・1視野の本数（マスクの設計ファイル待ち。本文には \mynote で残した）／寸法4つが設計値か実測値か／SU-8 2 と 3005 の混合比

## 2.7 細胞と長期タイムラプス計測
- P1 顕微鏡と環境: Ti-E 倒立、2.5 の 40×/0.95、ステージトップインキュベータ（TIZHB）30 °C、PFS、Micro-Manager 1.4
- P2 細胞株と培養条件: 野生型 FY18675（NBRP）。YE 寒天 → EMM 2% 20 mL 12 h → OD 0.01 に希釈 → 200 rpm で OD 0.2–0.5
- P3 細胞の準備と導入: 20 mL を 3,700 rpm 5 min で 100 倍濃縮、1 mL シリンジで注入、傾けて約 10 min 重力で導入、2 mL/h で灌流し余分な細胞を流す
- P4 培地交換と灌流: PHD ULTRA で 2 mL/h 一定。交換はチューブとコネクタごと。交換時刻はコネクタ内の気泡が映った次のフレーム
- P5 取得条件: 5 min 間隔、露光 60 ms、複数ステージ位置＋流路のない位置1つ。性能評価の記録は約 168 h（2020 時点）
- P6 参照グリッドの取得: 細胞のそばに培地だけの領域が残らないので、計測前に 9×9・0.1 µm 刻みのステージ変位で参照像を撮る（各変位で z スタックの合焦面、流路のない位置の像を引く）。中心像をフィードバックの基準にし、各視野を記録全長で ±0.4 µm 以内に保つ。各フレームには最も近い変位のグリッド像を対応させる（2.8.2）
- P7 蛍光像の同時取得: Hsp104-GFP の記録では反対側ポートから LED・GFP キューブ・ORCA-Fusion BT で同時取得

決めること: 性能評価の記録と実験1の株（論文は FY18675 野生型、3.3.1 は HN0101 mNeonGreen）／細胞の導入は重力（論文）か遠心 1,200 rpm × 2（旧本文）か／Hsp104-GFP を第3章で使わないなら P7 は消す／3本の記録のうち 2.9 は EMM 2% の1本で書く

## 2.8 画像解析
- P0 処理の順: 位置合わせ → 背景差分 → 培地屈折率の校正 → セグメンテーション → 系譜追跡 → 形状と体積 → 乾燥質量
- P1 位置合わせ: 各時点の位相像をグリッド中心像に ECC（並進のみ）で合わせる。計測中はステージ更新、記録後は各フレームの変位の計測
- P2 背景差分: 最も近い変位のグリッド像を背景にし、残差だけずらして、観察チャネル周りの帯で差をとる。残る 2π の整数倍と線形の傾きは細胞のない部分で推定して除く
- P3 培地屈折率の校正: BSA 0–5% w/v の系列を灌流、グリッド中心像を引いた位相の積分を濃度に直線当てはめ。傾き＝見ている培地の体積、傾きと切片から n_medium。BSA の屈折率増分は配列から計算し Zhao 2011 の波長・温度補正。0% を最後に再測定
- P4 セグメンテーション: Omnipose を自前の約 3,000 細胞で学習
- P5 系譜追跡: 面積で連結、閉端の細胞が起点。隣接2マスクの面積和が前フレームの1細胞と合えば分裂、閉端側が親の識別子を継ぐ。失敗は印。系譜＝閉端を占め続ける細胞の連なり
- P6 形状と体積: 楕円 Fourier 記述子で平滑化 → medial axis → 垂直な幅。長さ＝弧長、幅＝中央部の平均。体積は回転対称で断面を積算
- P7 乾燥質量: C = (1/α)(n_medium − n_water + (λ/2πV)∬Δφ dA)、α = 0.18 mL/g、n_water = 1.3312。乾燥質量 = CV

決めること: α はコードの値に合わせる（2.1 の文献値 0.18〜0.19 と整合させる）

## 2.9 性能評価
- 位相感度の理論: ノイズ項 z を加えた再構成 φ' の分散から σ_φ = (1/V)√(2/N_e)·√(A_ap/A_sensor)。背景差分で √2 倍。V^{-1} と N_e^{-1/2} に依存
- 位相ノイズ: 連続フレーム差の空間標準偏差/√2 を細胞のない領域で測り、上の shot-noise 限界と比べる（Figure 3A）
- 参照グリッド登録の精度: 公称ステージ変位と実測変位の差、誤差ベクトル（Figure 3B）
- ドリフト: 記録全長での位置ずれ、補正あり／なし（Figure 3C）
- 既知シフトの回収: 細胞のない領域に既知の sub-pixel 並進を与えて回収、MAE 3.8 nm（Figure 3D）
- 濃度校正の直線性: BSA 系列に対する位相の線形（Figure 2）

決めること: Figure 3A は測り直し／3B は参照グリッドの対応表を 32 bit 実数で作り直してから／Figure 2 の ver2
